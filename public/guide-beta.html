Muses 本地 Beta 指南Muses Local Beta Guide

从开发活动到可解释状态与可暂停的声音。

From development activity to explainable state and reversible audio.

1. 启动并采集1. Start and collect

发布包运行 node runtime.mjs install 后，以 node runtime.mjs start 启动，再打开 http://127.0.0.1:3001。源码开发可使用 pnpm dev；实际端口以启动输出为准。

In the bundle, run node runtime.mjs install, then node runtime.mjs start and open http://127.0.0.1:3001. For source development use pnpm dev; check the printed port.

服务启动后，在另一个终端选择要观察的目录：

After the server starts, select a directory in another terminal:

# bundle
node runtime.mjs watch --dir /path/to/project

# source checkout
pnpm watch -- --dir /path/to/project

认证开启时，可通过可信凭据管理器的管道向 --token-stdin 提供已有会话 token，仅限回环地址。不要将密码或 token 写入命令参数或 shell 历史。token 拥有对应账户的权限，失效后需重新提供。

With authentication enabled, pipe an existing session token from a trusted credential manager to --token-stdin; authenticated collection is loopback-only. Never put passwords or tokens in command arguments or shell history. A token has the account's permissions and must be replaced when expired.

2. 听到声音2. Start audio

watcher 根据真实文件变化上报事件；连续编辑需要至少三次事件、跨越 90 秒才能满足 BUILD 规则。达到策略门槛后，页面会显示声音建议。点击页面上的启动按钮；浏览器需要你的手势。你可以随时暂停，手动操作优先。

The watcher reports actual file changes. The BUILD rule requires at least three edit events spanning 90 seconds. Once the policy issues a suggestion, click the page's start control; browsers require a user gesture. You can pause at any time and manual input takes priority.

声音由浏览器在本机合成。公开 beta 不包含私有录音曲库，也不提供其播放器或回放体验。

The browser synthesizes sound locally. The public beta does not include the private recording library or its player and replay experience.

3. 隐私边界3. Privacy boundaries

默认不读取文件内容，也不发送相对文件路径；事件 subject 仍包含所选目录的名称。只有显式使用 --include-paths 才发送相对路径。匿名的发布包只适用于受信任的本机用户，本机其他进程仍可访问其 API；不要通过隧道或代理向外暴露。

The watcher does not read file contents or send relative file paths by default; the event subject still contains the selected directory name. Relative paths are sent only with --include-paths. The unauthenticated bundle is for one trusted local user; other local processes can access its API. Do not expose it through a tunnel or proxy.

发布后的原始事件保留期只影响新事件；设为 0 停止采集入库。过期的新事件按批清理，旧历史、备份和 SQLite 空闲空间不会被擦除。尚存的过期记录仍可通过历史 API 查询；保留期不是访问控制。会话历史保留、信号权重和应用排除尚未实现。

Published raw-event retention applies only to new events; zero disables ingestion. Expired managed events are deleted in batches, while legacy history, backups and SQLite free space are not erased. Expired rows still present can be read through historical API queries; retention is not access control. Session-history retention, signal weights and application exclusions are not implemented.

4. 数据与故障4. Data and troubleshooting

发布包把数据库和日志写入自身的 .muses/。请自行保管和备份。遇到异常时先检查本机服务、采集器输出与浏览器音量；不要直接清理已有数据库。是否公开、迁移或恢复数据需要单独评估。

The bundle stores its database and logs in its own .muses/ directory. Keep them private and back them up. For errors, check the local service, watcher output and browser volume first; do not delete an existing database. Publication, migration and restoration need separate review.
